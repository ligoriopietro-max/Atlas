# Atlas Public Test v0.1

Prima versione pubblica del prototipo Atlas.

Flusso: Questionario → Normalizer v0.1.5 → Engine v0.2.6 → Response Layer v0.1.

Questa versione non contiene ancora un database di professionisti/centri e non effettua ricerche reali. L'obiettivo è validare l'esperienza di orientamento con utenti reali.

Tutti i file necessari sono inclusi per una pubblicazione statica (es. GitHub Pages).
